fmflurry/harness-manifesto

One harness, two variants, three hosts

Formerly settings-opencode. The same harness installs on OpenCode, Claude Code, and Cursor. You pick a variant: Monolith (the default) or Conductor.

Host

OpenCode

Merges into ~/.config/opencode/. Entry: install.sh or bootstrap.sh. Config hub: opencode.jsonc.

Host

Claude Code

Optional ~/.claude/ mirror: settings, hooks, rules, agents, and synced skills. Same variant as OpenCode when you install both.

Host

Cursor

Plugin fmflurry-harness via install-cursor.sh (default Monolith). Version 0.4.36 in scripts/cursor-plugin/config.json. Same skills and ship loop; no per-agent write allowlist — agents are readonly or not.

Default install

Monolith

The primary agent writes, plans, and implements in the same session. Nothing has to run before the first edit.

  • 9 agents for review and noisy work: code-reviewer, security-reviewer, database-reviewer, ecosystem-auditor, e2e-runner, why-investigator, build-error-resolver, cop, comment-judge.
  • Folded roles are skills, not agents: planner, coder, tdd, git-workflow, writer, and the rest listed in variants/monolith/AGENTS.md.
  • /orchestrate is optional — it loads the conductor skill.
  • No first-tool gate. Live Postgres goes to database-reviewer or the main agent (postgres-dba is not installed).

Opt-in

Conductor

A read-only conductor routes every change. It cannot write — permissions deny write/edit. Delegation is mechanical, not just prose.

  • 26 agents: 1 conductor + 25 specialists, including planner, coder, writer, tdd-guide, git-specialist, scout, and postgres-dba.
  • First-tool gate: if a specialist matches, the first tool call must be that Task dispatch.
  • Before coder, writer, or tdd-guide, the conductor emits a 6-field brief (brief-contract).
  • Canonical flow: planner → (tdd-guide → coder) or coder → code-reviewer → verify → git-specialist.

How to install./install.sh --yes, ./install.sh --local, ./install-cursor.sh./install.sh conductor, ./install-cursor.sh --variant conductor. orchestration is an alias.

Shared rails (both variants, all three hosts)

  • Verification gate — no “done” without fresh build/test evidence.
  • Tool budget — verification is uncapped; exploratory shell is budgeted.
  • Secret-file guard, autonomy / /ship, worktree destruction safety, PR visual reports (docs/pr-reports/).
  • KPI journal at ~/.agent-harness/kpi/events.jsonl (OpenCode, Claude Code, and Cursor).
  • CodeMemory when on; cloud and remote sessions skip it unless FMFLURRY_CODEMEMORY=on.
./install.sh                         # interactive; default Monolith
./install.sh conductor               # Conductor on OpenCode + Claude Code
./install.sh monolith
./install-cursor.sh                  # Cursor plugin, default Monolith
./install-cursor.sh --variant conductor
Labels match variants/README.md, variants/monolith/AGENTS.md, variants/monolith/manifest.json, and the root README. Switching variants removes the other variant’s agents, commands, and rules.
