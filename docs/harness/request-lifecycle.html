Paths that break the rules

1. Conductor tries to write

On OpenCode and Claude Code the conductor has no file-mutation tool. On Cursor the conductor agent is marked readonly. That host has no per-agent write allowlist.

  1. Request arrives
  2. Harness loads on the host
  3. Conductor routes
  4. Write denied

2. “Done” without evidence

The verification gate forbids announcing done on hope or on a subagent’s word. Two failed fix passes on the same error leave the chart at Escalate to you — they do not loop forever.

  1. Main agent writes or Specialist writes
  2. Verification gate
  3. Fix pass
  4. Escalate to you

The diagram leaves out hook internals (secret-file guard, KPI lines, stop-gate counters) and the full /ship CI retry loop. Those are the same on both variants once review has passed.
