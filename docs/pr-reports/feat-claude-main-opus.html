fmflurry-harness 0.4.24 · feat/claude-main-opus

Claude Code's main agent defaults to the opus alias

Conductor and Monolith share .claude/settings.json. The session model is the alias opus. A fresh ~/.claude install and a fresh project .claude both receive it. An existing model value stays when the installer merges hooks.

How the setting lands

Template

.claude/settings.json carries the key for both variants. apply-monolith.mjs leaves that file alone.

"model": "opus"
▶

Seed

copy_claude_allowlist copies the file only when the destination has no settings.json. That covers global ~/.claude and ./install.sh --local.

▶

Merge

merge_agent_harness_settings writes opus when model is missing or empty. A string that is already set, including a user pin, is left as written.

Two variants, one Claude default

Conductor

Global ./install.sh default. The conductor routes and cannot write. postgres-dba is installed. The Claude session model is still opus.

Monolith

Cursor plugin and ./install.sh --local default. 9 agents. The main agent coordinates and may write. /orchestrate loads the conductor skill. Live Postgres goes to database-reviewer or the main agent when postgres-dba is absent.
