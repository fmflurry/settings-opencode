HARNESS · COMMIT TRACEABILITY

From a commit to its origin

Claude Code and OpenCode pass their session ID into a Git hook dispatcher. Each ordinary agent-shell commit records its installed harness and source revision.

01 · INSTALL

Capture

The installer records the source SHA and fingerprints managed files. An uncertain or changed installation is marked dirty.

02 · SESSION

Attribute

Claude SessionStart or OpenCode shell.env supplies session-scoped Git configuration. Existing repository hooks still run.

03 · COMMIT

Investigate

Git appends the current identity to the commit message. The merge gate checks the PR body for each record. Harness squash merges copy it into the commit message.

Harness: fmflurry-harness@0.4.36

Session-Id: <session ID>

Verification

Isolated Git tests cover session IDs, custom hooks, human commits, amended messages, and changed installations. Repository checks run separately.

Scope to verify

Support depends on each runtime delivering its session environment. Some OpenCode V2 versions do not invoke shell.env for Bash; command-line hook overrides can bypass Git hooks. GitHub website or API merges and bypassed guards are outside this best-effort scope.
