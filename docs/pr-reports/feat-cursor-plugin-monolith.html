Cursor sessions default to Monolith

The plugin Florian installs, and the files a project vendor writes for Cursor and coding bots, now follow the Monolith overlay. Conductor stays one flag away. Tier defaults stay on Cursor models.

Before Conductor only

The plugin build always copied the conductor. The primary agent could not write, and the first-tool gate ran before any edit.

▶
Build variant.mjs

node scripts/build-cursor-plugin.mjs defaults to Monolith. --variant conductor or HARNESS_VARIANT keeps the old tree.

▶
After Monolith installed

The primary agent writes. /orchestrate is optional. cop and comment-judge are the merged reviewers. .harness-variant records the choice.
