KPI lines now name the skill, the agent, and the tool result

The JSONL log at ~/.agent-harness/kpi/events.jsonl already stamped session and tool-call events. This change adds skill, agent, end-of-tool tool_result, and host token totals. Prompts, arguments, and absolute paths stay out of the file. AGENT_HARNESS_KPI=0 still writes nothing.

▶
3. Append tool_result

tool_name, duration_ms, ok. Skill and Task calls also set skill or agent on the start event.

▶
4. Report Same metrics

kpi-report.mjs still counts tool_call only. Unknown fields are ignored. Schema is in docs/kpi-events.md.
