fmflurry-harness 0.4.18 · feat/pr-show-me-report

Every harness pull request carries a show-me report

Opening or updating a PR now writes one offline HTML page and a PNG, commits them at a stable path, and blocks a gh or az body that omits the Visual report section. Conductor and Monolith share the skill. OpenCode, Claude Code, and Cursor run the same hook.

What changed

Before

The template stopped at Summary, Risk, How to revert, and Tier. The only picture was the ship outcome PNG at docs/agent-reports/<date>-<slug>.png, which the review key ignores.

▶

Gate

pr-visual-report.sh allows a body when ## Visual report has a checked Report line, a docs/pr-reports/<slug>.html link, and an image. A checked Skip line passes only with a reason of at least 8 characters.

▶

After

agent-harness pr-report writes docs/pr-reports/<branch-slug>.html and .png. Those files are committed before review. A cloud agent also copies them to /opt/cursor/artifacts/pr-reports/.

Where the hook runs

Three installs, one script

  • OpenCode: plugins/autonomy.ts calls visualReportRejection after the git guard. A missing hook fails open.
  • Claude Code: PreToolUse Bash in .claude/settings.json, and install.sh adds the same hook on upgrade.
  • Cursor: hooks/hooks.json from the plugin build, matcher Shell.

What the hook does not see

Cursor ManagePullRequest is not a shell command. The skill requires agent-harness pr-report-check --body-file before that tool. A title-only gh pr edit is left alone. A docs typo or a version bump only may check Skip and state the reason. The hook does not read the diff.

Risks

Skip is a statement, not a diff check

Any body with a checked Skip line and a reason of 8 or more characters passes. A non-trivial diff can still skip if the author writes that reason.

Host PR tools outside the shell

The hook blocks gh and az. A host tool that never runs those commands is gated only by pr-report-check in the skill.

The report is inside the review key

docs/pr-reports/ is not excluded the way docs/agent-reports/ is. Editing the report after a local review needs a new review.

Screenshot needs a local browser

pr-report exits 1 when neither screenshot.sh nor headless Chrome writes a PNG. It does not download a browser.
