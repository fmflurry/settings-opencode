Split project memory (“mémoire découpée”)

On by default. Turn it off with FMFLURRY_MEMORY=off. Each session loads a short AGENTS.md, then only the memory the task touches. CodeMemory is not involved.

What /memory-init scaffolds

AGENTS.md            ≤ ~80 lines, rules + pointers
docs/memory/
  INDEX.md           one line per doc
  glossary.md
  contexts/
    billing.md       read only if task touches BC
  decisions/
    0001-….md        ADR, immutable
    0002-….md        supersedes 0001 (kept)

Every doc has owner, reviewed, and refs frontmatter.

memory-lint.sh fails on

  • no frontmatter, a missing owner, or a missing reviewed
  • reviewed older than 90 days (day 90 passes, day 91 fails)
  • dead refs: a missing path, a path outside the repo, or path#Symbol with no whole-word match
  • with --body: no mémoire : màj / mémoire : aucun changement line

It passes without checking when there is no docs/memory or when FMFLURRY_MEMORY=off. An AGENTS.md over 80 lines only warns.

Who keeps it true

  • architect returns an ADR when a decision is made
  • writer writes the ADR and its INDEX line
  • doc-updater updates the touched BC's context file and sets reviewed
  • /pr body states the memory line

Risks
