fmflurry-harness 0.4.31 · fix/goal-state-per-branch

One goal file per repo, worktree, and branch

goal.json lived in the main checkout and every branch wrote the same file. goal set then kept the branch already stored in that file, so a checkout switch did not start a new goal. CLI and hooks now share goal-state.sh.

How a checkout gets its file

1. Scope
This worktree’s toplevel. If the process cwd is another worktree of the same repo, the cwd wins.
▶
2. Key
git common dir + worktree path + branch. Detached HEAD uses the literal name detached.
▶
3. File
.claude/state/goals/<sha1>.json
on the main checkout. autonomy.on stays shared.

A directory that is not a git repo still uses the flat goal.json. That path is the test seam, not a second branch.
