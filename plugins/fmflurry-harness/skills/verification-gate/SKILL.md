name: verification-gate
description: "Use before claiming work is done, or when a stop hook blocks the turn. Run the build, lint, and the tests that cover the change."
---

Before you say done, run the project build, lint, and the tests that cover the change, and paste the output. `ship-stop-gate` blocks a stop when that did not happen.

why-not-tooled: the stop hook is the gate. This skill does not restate the command matrix.
