Bug path

The page has to render with the network off.

1. still prose
2. HTML file written
3. blank offline page

Left out: which tag carried the external URL. The chart only shows that an external src or href makes the page blank.

May break

HTML only is allowed. Say in one line that no browser was found, and still hand over the file.
